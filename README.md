<center><p style="text-align: center;">This configurable mod makes Sand blocks instantly transform into Glass upon contact with lava. Perfect for creating glass farms or just adding a fun touch to your gameplay. &nbsp;</p>
<p style="text-align: center;"><img src="https://i.imgur.com/DXY3iwp.png" width="524" /></p></center>
<details>
<summary><strong>Configuration</strong></summary>
<p>You can configure this mod directly in-game or edit the JSON file <code>config/lavasand.json</code> in your profile folder.</p>
<center><p style="text-align: center;"><b>blocks_to_glass</b> - List of blocks that lava turns into glass</p></center>
